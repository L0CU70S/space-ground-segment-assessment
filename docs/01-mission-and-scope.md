# 1. Mission and Scope

## Mission

AuroraWatch-1 is a fictional LEO Earth-observation mission.

Its mission is to collect environmental imagery and transmit telemetry, mission data, and operational alerts to the ground segment.

## In Scope

- Mission Operations Center
- Operator workstations
- Mission control servers
- Telemetry processing systems
- Ground station gateway
- Identity and access management
- Remote administrative access
- Security monitoring
- Third-party ground station provider
- Command and telemetry workflows

## Out of Scope

- Physical satellite implementation
- Real RF testing
- Exploitation of real systems
- Spacecraft hardware security testing
- Launch vehicle security
- Real organization or customer data
- Real vulnerability disclosure

## Assumptions

- The mission uses a fictional satellite and fictional organizations.
- Operators access mission systems through controlled workstations.
- A third-party provider operates the ground station.
- Mission commands and telemetry are exchanged through defined interfaces.
- Security controls are proposed, not verified.

## Limitations

This is a simplified educational assessment and does not represent a real security assessment.
