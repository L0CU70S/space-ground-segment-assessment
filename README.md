# AuroraWatch-1 Ground Segment Cybersecurity Assessment

Fictional educational cybersecurity assessment of a satellite Ground Segment and Mission Operations Center.

## Disclaimer

AuroraWatch-1 is a fictional mission created for cybersecurity learning and portfolio purposes.

This project does not represent an operational satellite, organization, customer, security review, penetration test, compliance assessment, or real mission architecture.

It is not affiliated with NIST, SPARTA, CCSDS, Aerospace Corporation, ESA, NASA, or any other organization referenced in the project.

## Objective

This project applies publicly available cybersecurity guidance to a fictional satellite mission, with focus on:

- Ground Segment
- Mission Operations Center (MOC)
- Ground station interfaces
- Operator and administrator access
- Telemetry and telecommand workflows
- Third-party dependencies
- Threat modeling
- Risk assessment
- Detection and incident response
